# ProcureX Engine - Secure Procurement Framework

A robust full-stack vendor invoice and procurement handling engine built using clean modular engineering patterns.

## Technical Ecosystem
- **Frontend Layer:** ReactJS (Functional Hooks + Semantic CSS Variables)
- **Backend Architecture:** Node.js with Express framework
- **Data Repository Layer:** SQLite3 Structured Persistent Engine
